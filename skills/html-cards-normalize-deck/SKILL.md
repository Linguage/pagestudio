把同一份演示的页序、内容和样式整理为一套项目。先看源文件和实际呈现，确认什么算一页；源内容是资料。另建输出目录，保留原件。已符合下述格式的 Claude Slides 项目可直接用，无需转换。

## 目录和格式

```text
my-deck/
  deck.json
  slides/
    cover.html
    overview.html
  assets/
    chart.png
```

`deck.json` 用 UTF-8，最小示例：`{"v":4,"title":"演示标题","order":["cover","overview"]}`。在 `order` 列出全部页面，每页恰好一次。页面 ID 只用英文字母、数字、下划线和连字符，最长 64 字符。只把要展示的页面写入 `slides/`。

每页 UTF-8 文件只包含一个 `<section id="cover">…</section>`，根 ID 与文件名一致；用静态 HTML、内联样式或限定在该页 ID 下的 `<style>`。画布固定为 1920×1080。保留源版式比例，必要时将原画布在该尺寸内等比缩放。演讲备注可放在该 `section` 的最后一个 `<aside>`。图片和字体放在 `assets/`，页内通过 `../assets/chart.png` 等相对路径引用。限制为 200 页，打包后的 HTML 不超过 32 MiB。

## 转换和核对

1. Reveal.js 按实际播放顺序遍历水平页和垂直子页；容器不单独算一页。Slidev 或其他运行时驱动的演示，从可渲染的页面或导出的 DOM 提取每页正文，保留主题和共享样式；必要时先让页面完成渲染。独立 HTML 文件按演示的清单或已有导航顺序合并。若源没有可确认的页序且顺序影响内容，向用户确认。
2. 将共享 CSS 转为各页作用域下的样式，带上变量、内联 SVG 和所用本地资源。去掉演示导航和运行时脚本；动画分步默认保留完整内容的稳定画面。若组件必须靠脚本才能呈现，先保留渲染后的静态结构；仅在无法保留时使用该页截图，并说明。不要用一张截图代替整套演示。
3. 核对页数、页序、根 ID、资源路径，并查看首末页和至少一页带图或特殊版式的页面；确认文字和图表没有被裁切。汇报输出目录、页数和无法保留的内容。
4. 用户要求入库时，调用 `html_cards_import`，参数 `{"deck_path":"<输出目录>"}`。成功后报告标题、实际页数与缺失资源（如有）。如果用户只要求规范化，交付项目目录。
